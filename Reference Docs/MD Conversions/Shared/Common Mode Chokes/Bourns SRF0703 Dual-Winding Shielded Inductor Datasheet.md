## Features

- n Multiple applications: parallel, series, dual-inductor and transformer
- n Magnetically shielded, low radiation
- n Inductance range: 0.33 to 4000 μH
- n Rated current up to 6.19 A
- n RoHS compliant*

## Applications

- n SEPIC topology
- n Power supplies for:
- Communication equipment
- Notebooks, desktop computers, servers
- LCDs, flat panels, backlights
- Camcorders, HDTVs
